# sales-summary


## 🎯 Objective
Use SQL in Python to get sales data (total quantity, revenue) and show it using print and a bar chart.

## 🛠 Tools
- Python
- sqlite3
- pandas
- matplotlib

## 📌 What I Did
- Created a SQLite DB and a `sales` table
- Ran an SQL query to get total quantity and revenue per product
- Printed the result using pandas
- Plotted a revenue bar chart using matplotlib
- Saved chart as `sales_chart.png`

## ▶️ How to Run
```bash
pip install pandas matplotlib
python sales_summary.py
